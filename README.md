# 豚豚护送定时点击助手 v1.3

[下载 Windows v1.3](https://github.com/lihua2233/tuntun-click-assistant/releases/latest) · 内置预设：茉莉5940 `04:59:02`、i敏稳定5926 `04:59:15`。

双击 **豚豚定时点击助手 v1.3.exe** 即可运行，无需安装 Python。适用于 Windows 10/11 64 位。程序底部居中显示“公益软件 允许转载 严禁收费”，右侧显示 `@MinDna` 水印。

## 第一次使用：一键自动校准

1. 把游戏停在“守护豚豚”活动页，提前选好角色；打开 MuMu 操作录制列表并滚动到最顶部，录制必须处于停止状态。
2. 点击 **一键自动校准 → 进入游戏 → 暂停**。助手最小化，准备 3 秒后自动识别录制窗口中第一行最右侧的**蓝色播放箭头**，保存按钮中心。它不会点击或启动录制。
3. 助手识别“挑战”，点击进入选人页；看到“开始／确定”稳定出现后点击，用当前选中的角色完整进入一局。**这可能消耗一次挑战次数。**
4. 等待连续变化的倒计时，自动保存计时器中心及识别框大小，然后点击游戏右上角暂停。位置校准后自动滚动扫描操作录制列表，识别各行名称；扫描完成后助手恢复显示并保存位置和录制列表。
5. 在新增的 **使用录制** 下拉列表里选择要运行的录制，默认第一项；刷新时会保留仍能匹配的原选择。点击 **查看箭头定位** 可查看所选名称原始截图。如提示无法确认暂停成功，请手动检查游戏；助手不会重复点击暂停，以免把游戏恢复运行。
6. 正式任务前请手动返回活动页，再按 F8。移动窗口、调整画面大小或显示缩放后重新校准。

### 选择操作录制（新增）

- 自动校准并暂停游戏后，会滚动扫描当前 MuMu 操作录制列表，包括屏幕下方的项目。请停止所有录制，保持列表展开、名称和箭头可见；不要在扫描时操作鼠标。扫描完成后返回列表顶部。
- 在 **使用录制** 下拉框中选择需要的项目，例如第二行的“5912豚豚护送58_88左右点-ML”。选择会保存，重启程序后继续使用。
- **刷新录制列表** 只滚动识别列表，不进入游戏、不点击播放。新增、删除或重命名录制后可单独刷新。模拟器有搜索条件时，扫描的是筛选后的列表。
- 正式执行前，助手先滚动找到所选项目，按名称截图核对其蓝色播放箭头，然后进入挑战流程。重新定位在开始挑战前完成，不占用倒计时对时阶段。仅监听模式请等“已开始监听”后再手动开始挑战。
- 名称通过 Windows 本机中文 OCR 识别，可能出现错字；长名称在模拟器里被省略时只能识别显示部分。点击 **查看箭头定位** 核对原始名称截图。实际定位使用截图匹配，不依赖 OCR 拼写。无法区分的同名项目需要先改名或搜索筛选。
- 识别不到所选项目、按钮为停止方块、窗口移动、滚动失败或匹配不唯一时，停止本轮任务，不改选其他录制。更换窗口缩放后请重新校准并刷新名称。
- 若提示中文文字识别不可用，请在 Windows 设置的“语言和区域”中安装简体中文的“光学字符识别”功能，然后重试。也可继续使用手动校准①；手动记录①后会切换为手动坐标。
- 扫描与重新定位可按 F9 取消。名称扫描失败时仍保留已完成的游戏位置校准，可以稍后单独刷新。

自动校准的第一步仍要求最上面一行有蓝色播放箭头，用于初始化位置；它不会启动任何录制。

自动校准期间可以按 F9 中止；旧位置保持不变。如果中途已经进入游戏，请手动暂停。识别基于视频里的 MuMu 和游戏界面，界面改版或特殊缩放时可改用手动校准。校准时请保持窗口和鼠标不动，避免其他窗口遮挡。

### 手动校准（备用）

点击对应校准按钮，将鼠标放在目标中央，再按 F6。手动校准只记录位置，不点击。

- ① 录制开关：选定录制右侧的蓝色播放箭头中央。
- ② 挑战：活动页的“挑战”按钮。
- ③ 开始／确定：选人页的“确定”按钮。
- ④ 计时器中心：一次挑战中的完整 `MM:SS:CC` 中央。

在“时间与运行设置”中用“预览识别区域”核对完整的六位数字和两个冒号。手动改动任意位置后，正式运行按手动模式使用保存坐标。

## 使用时间预设（新增）

在“时间与运行设置”顶部的 **使用时间** 下拉框中选择时间预设，最多保存 10 个。

- 默认仅保留“茉莉5940”和“i敏稳定5926”两项预设。全新使用时选中“茉莉5940”，目标倒计时为 `04:59:02`；升级时移除原“佩恩5926~5940…”预设。
- **新建**：复制列表中预设 1 的最新设置，仅将目标倒计时置为空白，默认命名为“预设2”等。请填写时间后再执行。
- **重命名**：修改当前预设名称，不允许空名称或重复名称。
- **删除**：删除当前预设，至少保留一个。达到 10 个时需先删除一项才能新建。
- 每个预设分别保存目标倒计时、时间微调、挑战→开始间隔、识别框大小、运行模式和试运行状态。切换时保存当前修改，重启后恢复上次选择；关闭窗口或开始执行也会保存。
- 新建预设的“其余设置”始终取自列表第一个预设；如果删除原预设 1，则取当前列表的第一项。运行或校准过程中不能切换、增删或重命名预设。
- “使用时间”和“使用录制”独立选择，切换录制不会自动切换时间预设。

## 正式运行

1. 首个预设“茉莉5940”的目标倒计时为 `04:59:02`，第二项“i敏稳定5926”为 `04:59:15`，时间微调先填 `0`。如果已有 `settings.json`，仍优先使用此前保存的设置。
2. 选 **完整流程**，确保未勾选“试运行”。游戏应停在有“挑战”按钮的活动主页，角色已选好，录制项目未运行。
3. 按 **F8** 或点“开始执行”。准备 3 秒后，助手先重新定位所选录制，再点击挑战，默认等待 1800 毫秒，再点击开始／确定。等待加载时不启动固定倒数，而是读取游戏计时器对时。
4. 识别到至少 4 个连续递减读数后，计算目标时刻。触发前移动鼠标到录制开关，目标时刻发送一次点击，然后本轮助手任务结束。重新运行需再次按 F8。

选人界面加载较慢时，把“挑战→开始间隔”加大。助手不会自动选角色；如果进入选人界面后还需要操作，请使用“仅监听计时器”，手动完成开局。

运行后请不要移动鼠标、窗口或点击其他界面，以免改变目标位置。

## 输入目标时间和前后微调

目标倒计时使用三个独立小输入框，从左到右为 **分 : 秒 : 百分之一秒**。每格最多两位数字，离开输入框时会自动补齐两位；三格都填好后才能运行。新建时间预设时三格均为空。旧版保存的完整时间会自动拆分显示。

格式为 **分:秒:百分之一秒**，不是时:分:秒。`04:59:15` 就是剩余 4 分 59.15 秒；旧版保存的 `04:59.15` 格式仍可读取。

| 想要的效果 | 目标倒计时 | 微调（毫秒） | 对应剩余时间 |
|---|---|---:|---|
| 标准时刻 | 04:59:15 | 0 | 04:59:15 |
| 提前 20 毫秒 | 04:59:15 | -20 | 04:59:17 |
| 延后 20 毫秒 | 04:59:15 | +20 | 04:59:13 |
| 直接指定其他时间 | 04:58:75 | 0 | 04:58:75 |

倒计时的数字越大，触发越早。微调范围为 -5000～+5000 毫秒。计时器开始后需要短暂收集读数，因此微调后的实际目标上限是 `04:59:80`。

## 试运行与停止

- **试运行**：勾选后不会发送任何鼠标点击，也不会自动点击挑战／开始。按 F8，等待 3 秒后手动开局，助手只报告预计触发时刻。建议先这样验证识别区域。
- **仅监听计时器**：按 F8，等待 3 秒后手动开始挑战；助手会在指定时间点击录制开关。
- **F9**：停止助手或取消校准。F9 不能停止已经启动的模拟器操作录制；录制已启动时请在模拟器中手动停止。
- 计时器无法识别、暂停、持续读数异常，或明显错过目标时，助手会取消点击。首次等待计时器超时为 60 秒。
- 正式任务每次只发送一次录制开关点击；自动校准不点击录制开关。通过单实例保护避免同时打开两个助手。

## 精度与验证边界

提供的视频约为 29.95 帧/秒，画面中的计时器可能跳过某些百分之一秒读数，因此不一定出现恰好 `04:59:15` 的画面。

助手通过连续屏幕读数和高精度单调时钟估算两帧之间的点击时刻，不靠“从按开始起固定等待 1.12 秒”。加载时间不会直接计入倒计时。

**这不能保证游戏实际在 10 毫秒以内受理点击。** 屏幕刷新、帧延迟、系统调度、模拟器输入处理、录制脚本启动延迟都可能带来偏差。微调用来根据实际录屏结果补偿：实际启动偏晚就填负数，偏早就填正数。

`runs.jsonl` 中的 `scheduler_error_ms` 只表示助手发出点击与内部预计时刻的差值，不是游戏内实测误差，也不证明操作录制已成功启动。

本版本已用原视频全部 383 帧做回放检查：计时器出现后的 188 帧均读出有效时间；出现前未识别出计时器。另测试了正常触发、提前、延后、完整流程、试运行、停止、暂停、过期目标和无计时器场景。已检查中文窗口布局与打包程序启动。自动校准另用视频缩放回放和当前录制窗口截图检查了播放箭头定位，并测试完成、取消、超时和暂停未生效流程。新增录制选择功能通过现有录制窗口截图的行识别与本机 OCR 检查，并模拟测试了跨页扫描、屏幕下方录制定位、重启恢复选择、列表重排、同名冲突、滚动失败和 F9 取消。**没有在你的游戏中执行完整的自动校准实战点击验证；新列表滚动流程尚需实机验证。**

数字模板来自这段视频的字体。更换字体、极小画面、明显缩放或特殊显示效果可能影响识别；以“预览识别区域”的实际结果为准。

## 文件与源码

- `豚豚定时点击助手 v1.3.exe`：可独立运行；首次启动会解包到系统临时目录，可能需要数秒。
- `click_assistant.py`：中文窗口、校准、截图、点击及快捷键逻辑。
- `autocalibration.py`、`calibration.npz`：自动找按钮、录制播放箭头、进入游戏及暂停校准流程与图像模板。
- `recordings.py`、`recording_ocr.ps1`：录制列表滚动扫描、名称 OCR、选择保存与执行前重新定位。
- `engine.py`：倒计时识别、对时和时间格式处理。
- `digits.npz`：从视频字体提取的数字模板。
- `requirements.txt`：源码运行依赖。使用 Python 3.12 安装依赖后运行 `python click_assistant.py`。
- `settings.json`：首次校准后自动生成的位置和设置。
- `runs.jsonl`：成功触发或试运行命中后自动追加的记录。

设置和日志保存在程序所在文件夹。识别在本机完成，不上传屏幕图像。若模拟器以管理员权限运行，而助手提示输入被阻止，可将助手同样以管理员权限运行。


## 从源码运行与打包

在 Windows 上安装 Python 3.12，打开项目目录：

```powershell
python -m pip install -r requirements.txt
python click_assistant.py
```

运行 `build.ps1` 可使用 PyInstaller 生成独立程序，输出在 `dist/`。
