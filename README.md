# 豚豚护送定时点击助手 v1.2

[下载 Windows 版本](../../releases/latest) · 默认目标倒计时：`04:59:15`

双击 **豚豚定时点击助手 v1.2.exe** 即可运行，无需安装 Python。适用于 Windows 10/11 64 位。程序底部显示 `@MinDna` 水印。

## 第一次使用：一键自动校准

1. 把游戏停在“守护豚豚”活动页，提前选好角色；打开 MuMu 操作录制列表并滚动到最顶部，录制必须处于停止状态。
2. 点击 **一键自动校准 → 进入游戏 → 暂停**。助手最小化，准备 3 秒后自动识别录制窗口中第一行最右侧的**蓝色播放箭头**，保存按钮中心。它不会点击或启动录制。
3. 助手识别“挑战”，点击进入选人页；看到“开始／确定”稳定出现后点击，用当前选中的角色完整进入一局。**这可能消耗一次挑战次数。**
4. 等待连续变化的倒计时，自动保存计时器中心及识别框大小，然后点击游戏右上角暂停。完成后助手恢复显示并保存位置。
5. 点击 **查看箭头定位**，可查看实际识别到的箭头截图和绿色定位框。如提示无法确认暂停成功，请手动检查游戏；助手不会重复点击暂停，以免把游戏恢复运行。
6. 正式任务前请手动返回活动页，再按 F8。移动窗口、调整画面大小或显示缩放后重新校准。

**默认按最上面一行选择，不按录制名称搜索。** 如果“5912豚豚护送58_88左右点-ML”在第二行，需要把它放到最上面，或者用手动校准①指定该行的播放箭头。第一行按钮被遮挡、显示停止方块或无法识别时会停止校准，不改选下一行。

自动校准期间可以按 F9 中止；旧位置保持不变。如果中途已经进入游戏，请手动暂停。识别基于视频里的 MuMu 和游戏界面，界面改版或特殊缩放时可改用手动校准。校准时请保持窗口和鼠标不动，避免其他窗口遮挡。

### 手动校准（备用）

点击对应校准按钮，将鼠标放在目标中央，再按 F6。手动校准只记录位置，不点击。

- ① 录制开关：选定录制右侧的蓝色播放箭头中央。
- ② 挑战：活动页的“挑战”按钮。
- ③ 开始／确定：选人页的“确定”按钮。
- ④ 计时器中心：一次挑战中的完整 `MM:SS:CC` 中央。

在“时间与运行设置”中用“预览识别区域”核对完整的六位数字和两个冒号。手动改动任意位置后，正式运行按手动模式使用保存坐标。

## 正式运行

1. 默认目标倒计时为 `04:59:15`，时间微调先填 `0`。如果已有 `settings.json`，仍优先使用此前保存的设置。
2. 选 **完整流程**，确保未勾选“试运行”。游戏应停在有“挑战”按钮的活动主页，角色已选好，录制项目未运行。
3. 按 **F8** 或点“开始执行”。准备 3 秒后，助手点击挑战，默认等待 1800 毫秒，再点击开始／确定。等待加载时不启动固定倒数，而是读取游戏计时器对时。
4. 识别到至少 4 个连续递减读数后，计算目标时刻。触发前移动鼠标到录制开关，目标时刻发送一次点击，然后本轮助手任务结束。重新运行需再次按 F8。

选人界面加载较慢时，把“挑战→开始间隔”加大。助手不会自动选角色；如果进入选人界面后还需要操作，请使用“仅监听计时器”，手动完成开局。

运行后请不要移动鼠标、窗口或点击其他界面，以免改变目标位置。

## 输入目标时间和前后微调

格式为 **分:秒:百分之一秒**，不是时:分:秒。`04:59:15` 就是剩余 4 分 59.15 秒，也支持写成 `04:59.15`。

| 想要的效果 | 目标倒计时 | 微调（毫秒） | 对应剩余时间 |
|---|---|---:|---|
| 标准时刻 | 04:59:15 | 0 | 04:59:15 |
| 提前 20 毫秒 | 04:59:15 | -20 | 04:59:17 |
| 延后 20 毫秒 | 04:59:15 | +20 | 04:59:13 |
| 直接指定其他时间 | 04:58:75 | 0 | 04:58:75 |

倒计时的数字越大，触发越早。微调范围为 -5000～+5000 毫秒。计时器开始后需要短暂收集读数，因此微调后的实际目标上限是 `04:59:80`。

## 试运行与停止

- **试运行**：勾选后不会发送任何鼠标点击，也不会自动点击挑战／开始。按 F8，等待 3 秒后手动开局，助手只报告预计触发时刻。建议先这样验证识别区域。
- **仅监听计时器**：按 F8，等待 3 秒后手动开始挑战；助手会在指定时间点击录制开关。
- **F9**：停止助手或取消校准。F9 不能停止已经启动的模拟器操作录制；录制已启动时请在模拟器中手动停止。
- 计时器无法识别、暂停、持续读数异常，或明显错过目标时，助手会取消点击。首次等待计时器超时为 60 秒。
- 正式任务每次只发送一次录制开关点击；自动校准不点击录制开关。通过单实例保护避免同时打开两个助手。

## 精度与验证边界

提供的视频约为 29.95 帧/秒，画面中的计时器可能跳过某些百分之一秒读数，因此不一定出现恰好 `04:59:15` 的画面。

助手通过连续屏幕读数和高精度单调时钟估算两帧之间的点击时刻，不靠“从按开始起固定等待 1.12 秒”。加载时间不会直接计入倒计时。

**这不能保证游戏实际在 10 毫秒以内受理点击。** 屏幕刷新、帧延迟、系统调度、模拟器输入处理、录制脚本启动延迟都可能带来偏差。微调用来根据实际录屏结果补偿：实际启动偏晚就填负数，偏早就填正数。

`runs.jsonl` 中的 `scheduler_error_ms` 只表示助手发出点击与内部预计时刻的差值，不是游戏内实测误差，也不证明操作录制已成功启动。

本版本已用原视频全部 383 帧做回放检查：计时器出现后的 188 帧均读出有效时间；出现前未识别出计时器。另测试了正常触发、提前、延后、完整流程、试运行、停止、暂停、过期目标和无计时器场景。已检查中文窗口布局与打包程序启动。自动校准另用视频缩放回放和当前录制窗口截图检查了播放箭头定位，并测试完成、取消、超时和暂停未生效流程。**没有在你的游戏中执行完整的自动校准实战点击验证。**

数字模板来自这段视频的字体。更换字体、极小画面、明显缩放或特殊显示效果可能影响识别；以“预览识别区域”的实际结果为准。

## 文件与源码

- `豚豚定时点击助手 v1.2.exe`：可独立运行；首次启动会解包到系统临时目录，可能需要数秒。
- `click_assistant.py`：中文窗口、校准、截图、点击及快捷键逻辑。
- `autocalibration.py`、`calibration.npz`：自动找按钮、录制播放箭头、进入游戏及暂停校准流程与图像模板。
- `engine.py`：倒计时识别、对时和时间格式处理。
- `digits.npz`：从视频字体提取的数字模板。
- `requirements.txt`：源码运行依赖。使用 Python 3.12 安装依赖后运行 `python click_assistant.py`。
- `settings.json`：首次校准后自动生成的位置和设置。
- `runs.jsonl`：成功触发或试运行命中后自动追加的记录。

设置和日志保存在程序所在文件夹。识别在本机完成，不上传屏幕图像。若模拟器以管理员权限运行，而助手提示输入被阻止，可将助手同样以管理员权限运行。

## 从源码运行与打包

在 Windows 上安装 Python 3.12，打开项目目录：

```powershell
python -m pip install -r requirements.txt
python click_assistant.py
```

运行 `build.ps1` 可使用 PyInstaller 生成独立程序，输出在 `dist/`。首次执行会安装 Python 依赖与打包工具。
